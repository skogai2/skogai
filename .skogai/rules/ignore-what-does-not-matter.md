---
description: Never spend effort on things that have no impact by definition; park them as a task and move on
priority: 40
---
Do not actively take care of anything that, by definition, has no impact on anything: cosmetic
clutter, dangling symlinks, tidiness nobody reads, harmless leftovers. If it will not annoy you,
skogix, or any process, it is not worth the time.

- **Park, don't fix:** write it as one task in the nearest task, todo, or dump file (in
  `~/skogai`: `.skogai/tasks/`, priority `low`), then go back to what matters.
- **Do not investigate, explain at length, or ask about it.** No question, no options list, no
  30-60 minute detour. One line in a task file is the whole cost.
- **Test before spending effort:** does it block a command, corrupt data, leak a secret, or
  mislead a reader? If not, park it. If it does, it is not this rule's case.
- **Spending time on it anyway is the failure**, not the thing itself. Consequential problems
  (a live symlink with a dead interpreter, a secret in git) still get fixed.
