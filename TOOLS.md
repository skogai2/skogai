# Tools

The tools available on this machine, what each is for, and how skogai uses
it. Purposes marked *unverified* were read from the name only; check with
`--help` before relying on them.

## Herdr and worktrees

- **herdr** (`/usr/bin/herdr`): terminal workspace manager for coding agents.
  Panes, tabs, workspaces and agent state. Setup and conventions are in
  `projects/config/herdr.md`; the agent skill is `herdr --skill`.
- **wt** (worktrunk, `mise`): git worktree management. `wt merge` merges the
  current branch into the default branch; the primary worktree is kept.
  Config and hooks are in worktrunk's guidance (`wt --help`).

## Agents and orchestration

- **claude** (Claude Code): the agent CLI. skogai's orchestrator is started by
  `orchestration/launch.sh`; workers are dispatched by `orchestration/dispatch.sh`.
- **gptme-coordination** (`/skogai/bin`): work claims, messages, facts and a
  queue between agents. Commands: `work-submit`, `work-claim`,
  `work-complete`, `work-abandon`, `work-list`, `inbox`, `send`, `announce`,
  `fact-publish`, `fact-query`, `fact-list`, `status`, `queue-*`. Database:
  `/skogai/coordination/coord.db`. Sender identity is not signed.
- **gptodo** (`/skogai/bin`): task management for gptme agent workspaces.
  Status views (`list`, `show`, `status`, `next`, `ready`) and metadata editing.
- **gptmail** (`/skogai/bin`): email system for agent communication.
- **agentboard** (`/skogai/bin`): git-native agent forum. Posts, threaded
  comments and @mentions over shared git repos.
- **gptme-agent** (`/skogai/bin`): sets up and runs autonomous gptme agents on
  a schedule, through systemd.

## Repos and environment

- **skogai** (`~/.local/bin`): the `/skogai` command. Subcommands: `path`,
  `env`, `link`, `init`, `update`, `install`, `config`. Config model is in
  `projects/skogai-cli/docs/CONFIG.md`.
- **gh**: GitHub CLI, logged in as `Skogix`. Workers open PRs with it.
- **atuin**: shell history sync and env var/alias management. Rules are in
  `projects/config/atuin.md`. Never store secrets there.
- **mise**: runtimes and tool versions (`uv`, `gh`, `claude`, `wt`, ...).
- **uv**: Python tool runner. `bin/` launchers use `uv tool run`.
- **fish**, **tmux**, **nvim**, **jq**, **argc**: the shell, the multiplexer,
  the editor, JSON querying, and the completion generator.

## gptme tools in /skogai/bin

The `gptme-*` launchers are generated by `dash-skogai/scripts/gen-bin.py` from
pinned packages. Grouped by name; *unverified* unless noted.

- **Core:** `gptme`, `gptme-tui`, `gptme-server`, `gptme-acp`, `gptme-mcp-server`
- **Agent memory and hooks:** `gptme-cc-memory-extract`,
  `gptme-cc-memory-prompt-submit`, `gptme-cc-memory-stop-hook`, `gptme-util`,
  `gptme-wisdom`, `gptme-wisdom-mcp`, `gptme-lessons-mcp`
- **Work and sessions:** `gptme-checkpoint`, `gptme-resume`, `gptme-sessions`,
  `gptme-runloops`, `gptme-service`, `gptme-onboard`, `gptme-init`
- **Status:** `gptme-status`, `gptme-stats`, `gptme-dashboard`,
  `gptme-activity-summary`, `gptme-doctor`
- **Code and retrieval:** `gptme-codegraph`, `gptme-codegraph-commit-map`,
  `gptme-codegraph-mcp`, `gptme-rag`, `gptme-convert`
- **Voice and messaging:** `gptme-voice-*`, `gptme-voice-call`,
  `gptme-whatsapp-setup`
- **Eval (unverified):** `gptme-eval`, `gptme-eval-swebench`,
  `gptme-eval-tbench`, `gptme-eval-trends`, `gptme-dataset`, `gptme-dspy`
- **Other (unverified):** `gptme-attest`, `gptme-auth`, `gptme-subscription`,
  `gptme-vision-node`, `gptme-wut`, `gptme-tutorial`
